# Bootcamp Itaú: Java com Inteligência Artificial

Repositório de estudos com os fundamentos, exercícios e projetos desenvolvidos durante o **Bootcamp Itaú - Java com Inteligência Artificial**, na plataforma DIO.

> **Status: em andamento.** O conteúdo é adicionado conforme os módulos são concluídos.

## Objetivo

Reunir em um só lugar o que aprendi no bootcamp: anotações próprias, código dos exercícios e projetos práticos, organizados por módulo. O repositório também serve para registrar minha evolução ao longo do curso.

## Tecnologias

- Java (JDK 21)
- Maven (a partir dos projetos Spring)

- Git e GitHub
- VS Code

## Como executar os exemplos

Os exercícios dos primeiros módulos são arquivos `.java` simples. Com o JDK instalado, a partir da raiz do repositório:

```
javac -d bin caminho/da/pasta/Arquivo.java
java -cp bin NomeDaClasse
```

Os projetos Spring terão instruções próprias nos respectivos READMEs.
